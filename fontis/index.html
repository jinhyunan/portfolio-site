  1. parsing — Input authorized PDF · Output page JSON · Metadata document/page · Gate page count
  2. tables — Input detected grids · Output normalized rows · Metadata units/period · Gate malformed cells
  3. images — Input chart candidates · Output validated descriptions · Metadata page/image ID · Gate decorative or unreadable
  4. chunking — Input text/table/image evidence · Output stable chunks · Metadata provenance · Gate duplicate IDs
  5. embeddings — Input 401 chunks · Output FAISS vectors · Metadata position map · Gate vector/order mismatch
  6. retrieval — Input question · Output BM25 + vector + RRF · Metadata scores/source · Gate dedupe and threshold
  7. grounded QA — Input typed evidence · Output answer or refusal · Metadata document/page · Gate unsupported claims
