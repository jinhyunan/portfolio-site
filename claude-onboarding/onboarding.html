Write a one-page analysis memo for the CEO.

1. Three key judgments so far
2. Channel performance comparison
3. Purchase motives and complaints from the customer survey
4. Position relative to competitors
5. Key messages for next quarter's business plan

Please:
- Ground all numbers in the attached data.
- Do not invent external market figures you do not know.
- End with a separate “Additional data to verify” section.
Based on the analysis above, create a five-slide presentation outline.

Draft your first Skill

Have Claude write a first draft of SKILL.md.

Copy the prompt below, insert your answers from step 6, and send it to Claude.

I write [task/document name] every week.

Good examples: [key features of examples 1 and 2]
Poor example: [what went wrong in example 3]
Required rules: [format/tone/judgment criteria]

Draft a SKILL.md that helps me do this task consistently next time.

Include these sections:
- Purpose
- Input materials
- Working procedure
- Quality criteria
- Prohibited actions

If anything is missing, end with a separate “What else you need to tell me” list.
This is not the end. Claude's follow-up questions reveal rules you have not yet articulated. Add your answers to SKILL.md and run it once more to complete a first version.
